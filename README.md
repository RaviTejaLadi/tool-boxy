## 🚀 Getting Started

### ✅ Prerequisites

- **Node.js** `20+` (recommended)
- **npm** (comes with Node)

### 📥 Install & run

```bash
# 1. Clone the repo
git clone https://github.com/tool-boxy/tool-boxy.git
cd tool-boxy

# 2. Install dependencies
npm install

# 3. Start the dev server
npm run dev
```

Then open the URL Vite prints — usually **http://localhost:5173** 🎉

### 📜 Scripts

| Command              | What it does                    |
| :------------------- | :------------------------------ |
| `npm run dev`        | 🔥 Start Vite dev server        |
| `npm run build`      | 🏗️ Typecheck + production build |
| `npm run preview`    | 👀 Preview the production build |
| `npm run lint`       | 🔍 Lint with oxlint             |
| `npm run format`     | ✨ Format with Prettier         |
| `npm run pre-commit` | ✅ Format → lint → build        |

## 📁 Project Structure

```text
src/
├── 🧩 components/     # Shared UI (shadcn), theme, syntax highlighting
├── ⚙️  config/        # Tool registry — titles, routes, categories
├── 🧰 features/       # One folder per tool (UI · stores · helpers)
├── 🪝 hooks/          # Shared hooks (e.g. favorites)
├── 🖼️  layouts/       # App shell & sidebar
├── 📚 lib/            # Shared utilities
└── 📄 pages/          # Thin route pages that mount features
```

Each tool lives under `src/features/<ToolName>/` with its own UI, store, and
helpers.

- Routes → `src/App.tsx`
- Catalog → `src/config/tools.ts`

## 🧩 Adding a Tool

Want to ship a new utility? Here’s the usual flow:

1. **Create** a feature folder under `src/features/YourTool/`
2. **Add** a page in `src/pages/YourToolPage.tsx`
3. **Register** the route in `src/App.tsx`
4. **List** it in `src/config/tools.ts` (title, description, category, icon)
5. **Verify** with `npm run pre-commit`
